لوحة التحكم الإدارية (Admin Portal) —المتطلبات الفنية

نحتاج إلى لوحة تحكم إدارية آمنة ومتقدّمة تكون هي مركز التحكم الداخلي لمنصتنا القانونية الخاصة بالـPDPL.
هذه اللوحة لن يراها العملاء؛ هي مخصّصة فقط لفريق العمل لإدارة النظام بكل تفاصيله.

هدف لوحة التحكم

يجب أن تمنحنا اللوحة القدرة الكاملة على:
	•	إدارة المستخدمين والاشتراكات
	•	متابعة السياسات التي يُنشئها العملاء
	•	مراقبة سجلات الامتثال
	•	التعامل مع طلبات العملاء (DSAR)
	•	تحديث المحتوى القانوني والقوالب
	•	مراقبة أداء النظام والأخطاء

هي العقل التشغيلي الأساسي للمنصة.

المميزات الأساسية المطلوبة

1) تسجيل الدخول والصلاحيات
	•	تسجيل دخول آمن للإدارة
	•	نظام صلاحيات (مدير عام – فريق قانوني – فريق دعم)
	•	تتبع النشاط وإنشاء سجلات تدقيق (Audit Logs)

2) إدارة المستخدمين
	•	عرض جميع العملاء المسجلين
	•	تفعيل/إيقاف الحسابات
	•	تعديل بيانات المستخدم عند الحاجة
	•	متابعة نشاط كل عميل
	•	عرض حالة الاشتراك والدفع

3) إدارة طلبات العملاء (DSAR)
	•	لوحة تعرض جميع طلبات العملاء مثل:
	•	حذف البيانات
	•	تصدير البيانات
	•	تصحيح البيانات
	•	تغيير حالة الطلب (مستلم – قيد المعالجة – مكتمل)
	•	إضافة ملاحظات داخلية لكل طلب
	•	تتبع الوقت وفقًا لمتطلبات PDPL

4) إدارة السياسات والمحتوى
	•	عرض جميع سياسات الخصوصية وملفات الارتباط التي أنشأها العملاء
	•	القدرة على تعديل أو إضافة أو تحديث البنود القانونية
	•	التحكم في الإصدارات (Version Control)
	•	تحديث القوالب ودفع التعديلات للعملاء تلقائيًا

5) أدوات الامتثال (Compliance Tools)
	•	الوصول إلى سجلات ROPA الخاصة بالعملاء
	•	مراجعتها وتصديرها عند الحاجة
	•	عرض جميع تقييمات DPIA المقدّمة من العملاء وحالة كل منها

6) مراقبة النظام (System Monitoring)
	•	عرض الأخطاء والتنبيهات
	•	مراقبة أداء الـ API
	•	مراقبة حالة الخادم (Server Health)
	•	إشعارات عند حدوث تغييرات أو مشاكل مهمة

7) المالية والفوترة
	•	عرض الاشتراكات الحالية
	•	سجلات المدفوعات
	•	متابعة الإيرادات الشهرية

8) واجهة بسيطة وسهلة الاستخدام
	•	تصميم منظم وواضح
	•	سرعة في التنقل
	•	دعم الوضع المظلم والفاتح (اختياري)
